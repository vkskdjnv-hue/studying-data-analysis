## 模块一：Pandas 基础与 DataFrame (24分钟)
*对应图片：学习 pandas、学习 DataFrame*

### 知识点 1：Pandas 核心数据结构 Series 与 DataFrame
**讲解**：Series 是带==标签==的一维数组；DataFrame 是带==行索引==和==列标签==的二维表格，是 Pandas 的核心。

**📝 练习 1**：创建一个 DataFrame，包含三列：`'产品'` (A, B, C)、`'价格'` (10, 20, 30)、`'销量'` (100, 200, 150)。

**✅ 解答 1**：

```python
import pandas as pd

data = {
    '产品': ['A', 'B', 'C'],
    '价格': [10, 20, 30],
    '销量': [100, 200, 150]
}
df = pd.DataFrame(data)
print(df)
```

---

### 知识点 2：DataFrame 的属性查看
**讲解**：常用属性有 `shape` (形状)、`columns` (列名)、`dtypes` (数据类型)、`index` (行索引)。

**📝 练习 2**：基于练习1的 `df`，打印出它的行数和列数，以及每一列的数据类型。

**✅ 解答 2**：
```python
print("形状:", df.shape)
print("列名:", df.columns.tolist())
print("数据类型:\n", df.dtypes)
```

---

### 知识点 3：DataFrame 的索引与切片 (loc 与 iloc)
**讲解**：`loc` 按标签索引，`iloc` 按位置索引。这是 Pandas 最基础也最容易混淆的操作。

**📝 练习 3**：基于练习1的 `df`，用 `iloc` 取出第2行数据，用 `loc` 取出 `'价格'` 这一列。

**✅ 解答 3**：
```python
# iloc 按位置 (第2行，索引为1)
print("第2行数据:\n", df.iloc[1])

# loc 按标签 (取 '价格' 列)
print("价格列:\n", df.loc[:, '价格'])
```

## 模块二：数据读取 (24分钟)
*对应图片：学习 数据读取*

### 知识点 4：读取 CSV 文件基础
**讲解**：`pd.read_csv()` 是最常用的读取函数，需要处理路径和编码问题。

**📝 练习 4**：创建一个名为 `test.csv` 的文件（用代码生成），包含 `id,name` 两列，然后读取它。

**✅ 解答 4**：
```python
# 先生成文件
import pandas as pd
df_temp = pd.DataFrame({'id': [1, 2], 'name': ['Tom', 'Jerry']})
df_temp.to_csv('test.csv', index=False)

# 读取文件
df = pd.read_csv('test.csv')
print(df)	
```

---

### 知识点 5：读取时的常用参数 (usecols, nrows)
**讲解**：处理大文件时，`usecols` 只读取需要的列，`nrows` 只读取前 N 行，能极大节省内存。

**📝 练习 5**：读取 `test.csv`，但只读取 `name` 列，且只读取前 1 行。

**✅ 解答 5**：
```python
df = pd.read_csv('test.csv', usecols=['name'], nrows=1)
print(df)
```

---

### 知识点 6：读取 Excel 文件
**讲解**：`pd.read_excel()` 用于读取 Excel，需要安装 `openpyxl` 库。参数 `sheet_name` 可指定工作表。

**📝 练习 6**：写代码将练习1的 `df` 保存为 `test.xlsx`，然后重新读取它，指定读取工作表名为 `Sheet1`。

**✅ 解答 6**：
```python
# 保存

# 读取
df_excel = pd.read_excel('test.xlsx', sheet_name='Sheet1')

```

## 模块三：缺失值处理 (24分钟)
*对应图片：学习 缺失值处理*

### 知识点 7：检测缺失值
**讲解**：`isnull()` 判断是否为空，`isnull().sum()` 统计每列缺失数量，这是清洗数据的第一步。

**📝 练习 7**：创建含空值的 DataFrame：`{'A': [1, None, 3], 'B': [None, 5, 6]}`，统计每列缺失值数量。

**✅ 解答 7**：
```python
import numpy as np
df = pd.DataFrame({'A': [1, np.nan, 3], 'B': [np.nan, 5, 6]})
print(df.isnull().sum())
# 输出: A 1, B 1
```

---

### 知识点 8：删除缺失值 (dropna)
**讲解**：`dropna()` 删除含空值的行；`axis=1` 删除含空值的列；`how='all'` 表示全为空才删。

**📝 练习 8**：基于练习7的 `df`，删除任何含有空值的行，并打印结果。

**✅ 解答 8**：
```python
df_dropped = df.dropna()
print(df_dropped)
# 只剩第3行 (索引2) 的数据
```

---

### 知识点 9：填充缺失值 (fillna)
**讲解**：`fillna()` 可用固定值、均值、中位数、众数填充。这是比删除更常用的策略。

**📝 练习 9**：基于练习7的 `df`，将 A 列的空值用 0 填充，将 B 列的空值用 B 列的均值填充。

**✅ 解答 9**：
```python
df['A'] = df['A'].fillna(0)
df['B'] = df['B'].fillna(df['B'].mean()) 这里需要先转换为浮点型
print(df)
```

**📝 练习 12**：在 `df` 中新增一列 `'销售额'`，值为 `'价格' * '销量'`。再新增一列 `'等级'`，价格>20为'高'，否则为'低'。

## 模块五：实战 - 读取 CSV 并做简单分析 (24分钟)
*对应图片：练习 读取 CSV 并做简单分析*

### 知识点 13：分组聚合 (groupby)
**讲解**：`groupby('列名')['目标列'].agg(['sum','mean'])` 是数据分析的灵魂。

**📝 练习 13**：创建一个销售表：`{'城市': ['北京','上海','北京','上海'], '销售额': [100, 200, 300, 400]}`，按城市分组计算总销售额。

**✅ 解答 13**：

```python
df_sales = pd.DataFrame({'城市': ['北京','上海','北京','上海'], '销售额': [100, 200, 300, 400]})
result = df_sales.groupby('城市')['销售额'].sum()
print(result)
# 北京 400, 上海 600
```

---

### 知识点 14：聚合多列与多函数
**讲解**：`agg()` 可同时应用多个函数，输出多列结果。

**📝 练习 14**：基于练习13的 `df_sales`，按城市分组，同时计算销售额的 `sum`、`mean`、`count`。

**✅ 解答 14**：
```python
result = df_sales.groupby('城市')['销售额'].agg(['sum', 'mean', 'count'])
print(result)
```

### 知识点 15：综合实战 - 读取 CSV 并完整分析
**讲解**：结合读取、清洗、筛选、分组的完整流程。

**📝 练习 15**：
1. 生成 `sales.csv`：含 `城市`、`产品`、`销售额`，故意留一个 `销售额` 空值。
2. 读取 CSV。
3. 用该列均值填充 `销售额` 空值。
4. 按城市分组计算总销售额。
5. ==筛选出总销售额大于 300 的城市。==

**✅ 解答 15**：

```python
import pandas as pd
import numpy as np

# 1. 生成数据
data = {
    '城市': ['北京', '上海', '北京', '上海', '广州'],
    '产品': ['A', 'B', 'C', 'A', 'B'],
    '销售额': [100, 200, np.nan, 400, 50]
}
df = pd.DataFrame(data)
df.to_csv('sales.csv', index=False)

# 2. 读取
df = pd.read_csv('sales.csv')

# 3. 填充空值
df['销售额'] = df['销售额'].fillna(df['销售额'].mean())
print("--- 填充后 ---\n", df)

# 4. 按城市分组汇总
city_total = df.groupby('城市')['销售额'].sum()
print("\n--- 各城市总销售额 ---\n", city_total)

# 5. 筛选
result = city_total[city_total > 300]
print("\n--- 总销售额大于300的城市 ---\n", result)
# 北京: 100+225=325 > 300 ✅
# 上海: 200+400=600 > 300 ✅
# 广州: 50 ❌
```
