### 🕐 第一部分：SELECT 与 WHERE (基础查询与条件过滤)
**预计耗时：25分钟**

#### 知识点讲解
1.  **SELECT**：用于从表中选取数据。`SELECT *` 选所有列，`SELECT name, salary` 选指定列。
2.  **WHERE**：用于过滤记录。
    *   比较运算符：`=`, `>`, `<`, `>=`, `<=`, `!=`
    *   逻辑运算符：`AND`, `OR`, `NOT`
    *   范围：`BETWEEN ... AND ...`  ==闭区间==
    *   模糊查询：`LIKE` (% 匹配任意字符，_ 匹配单个字符)
    *   空值：`IS NULL`, `IS NOT NULL`

#### 📝 练习题 (1-5题)
1.  查询所有员工的姓名和工资。
2.  查询工资大于 10000 的所有员工信息。
3.  查询“研发部”且工资大于 15000 的员工姓名。
4.  查询姓“张”的员工信息（使用 LIKE）。
5.  查询工资在 8000 到 15000 之间的员工姓名和工资。

<details>
<summary>点击查看答案</summary>

```sql
-- 1. 
SELECT name, salary FROM employees;

-- 2. 
SELECT * FROM employees WHERE salary > 10000;

-- 3. 
SELECT name FROM employees WHERE department = '研发部' AND salary > 15000;

-- 4. 
SELECT * FROM employees WHERE name LIKE '张%';

-- 5. 
SELECT name, salary FROM employees WHERE salary BETWEEN 8000 AND 15000;
```
</details>

### 🕑 第二部分：ORDER BY (排序)
**预计耗时：15分钟**	

#### 知识点讲解
*   **ORDER BY**：用于对结果集进行排序。
*   默认是升序 `ASC`，降序使用 `DESC`。
    *   可以==多列排序==：`ORDER BY department ASC, salary DESC` (先按部门升序，部门相同时按工资降序)。


#### 📝 练习题 (6-8题)
6.  查询所有员工信息，按工资从高到低排序。
7.  查询“销售部”的员工，按入职日期从早到晚排序。
8.  查询所有员工，先按部门名称升序排列，如果部门相同，则按工资降序排列。

<details>
<summary>点击查看答案</summary>

```sql
-- 6. 
SELECT * FROM employees ORDER BY salary DESC;

-- 7. 
SELECT * FROM employees WHERE department = '销售部' ORDER BY hire_date ASC;

-- 8. 
SELECT * FROM employees ORDER BY department ASC, salary DESC;
```
</details>

### 🕒 第三部分：GROUP BY (分组与聚合)
**预计耗时：25分钟**

#### 知识点讲解
*   **GROUP BY**：将数据按某列的值进行分组。
*   **聚合函数**（常配合 GROUP BY 使用）：
    *   `COUNT()`：计数
    *   `SUM()`：求和
    *   `AVG()`：平均值
    *   `MAX()` / `MIN()`：最大/最小值
*   **HAVING**：对分组后的结果进行过滤（WHERE 是在分组前过滤，HAVING 是在分组后过滤）。

#### 📝 练习题 (9-12题)
9.  统计每个部门有多少名员工。
10. 计算每个部门的平均工资。
11. 统计每个城市的员工人数，并按人数从多到少排序。
12. 查询平均工资大于 10000 的部门名称及其平均工资。

<details>
<summary>点击查看答案</summary>

```sql
-- 9. 
SELECT department, COUNT(*) FROM employees GROUP BY department;

-- 10. 
SELECT department, AVG(salary) FROM employees GROUP BY department;

-- 11. 
SELECT city, COUNT(*) as emp_count FROM employees GROUP BY city ORDER BY emp_count DESC;

-- 12. 
SELECT department, AVG(salary) FROM employees GROUP BY department HAVING AVG(salary) > 10000;
```
</details>

### 🕓 第四部分：综合挑战 (检验成果)
**预计耗时：25分钟 (包含剩余3道练习题)**

#### 📝 练习题 (13-15题)
13. **综合**：查询每个部门的最高工资，并按最高工资降序排列。
14. **综合**：查询“北京”地区每个部门的平均工资，只显示平均工资大于 12000 的部门。
15. **终极挑战**：查询入职年份在 2020 年之前的员工，按部门分组，统计每个部门的人数，并按人数降序排列。

<details>
<summary>点击查看答案</summary>

```sql
-- 13. 
SELECT department, MAX(salary) as max_sal 
FROM employees 
GROUP BY department 
ORDER BY max_sal DESC;

-- 14. 
SELECT department, AVG(salary) as avg_sal 
FROM employees 
WHERE city = '北京' 
GROUP BY department 
HAVING avg_sal > 12000;

-- 15. 
SELECT department, COUNT(*) as emp_count 
FROM employees 
WHERE hire_date < '2020-01-01' 
GROUP BY department 
ORDER BY emp_count DESC;
```
</details>

### 💡 学习建议
1.  **不要死记硬背**：重点理解 `WHERE`（分组前过滤）和 `HAVING`（分组后过滤）的区别。
2.  **执行顺序**：SQL 的执行顺序通常是 `FROM` -> `WHERE` -> `GROUP BY` -> `HAVING` -> `SELECT` -> `ORDER BY`。理解这个顺序能帮你解决大部分逻辑错误。
